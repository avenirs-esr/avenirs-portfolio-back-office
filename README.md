# avenirs-portfolio-back-office

Back Office module for Avenirs-ESR ePortfolio

## Overview

The back office module provides administrative capabilities for the Avenirs-ESR ePortfolio platform. It enables system administrators and institutional managers to configure and manage the application at both system and institutional levels.

## Key Features

- **Application Configuration**: System-wide settings and parameters management
- **Institution Setup**: Multi-tenant institution configuration and customization
- **Administrative Tools**: User management, monitoring, and system administration features

## Purpose

This module serves as the administrative interface for managing the ePortfolio platform, allowing administrators to configure institutions, manage system settings, and oversee the overall operation of the application.
